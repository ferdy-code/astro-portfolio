## The problem

Most "AI assistant" projects stop at a single chatbot demo. Running several distinct, useful agents long-term — each with its own persona and job — is a different problem: process isolation, independent state, and framework choices that hold up outside a notebook.

## The approach

Four self-hosted agents run as independent profiles on Telegram: Kuma, a Japanese tutor; Coach Rex, an English/IELTS coach; Coach Titan, a fitness and nutrition coach; and Sora, a social media manager. Each is built on the OpenClaw and Hermes agent frameworks.

## The stack

OpenClaw and Hermes for the agent frameworks, deployed to Telegram as the interface.

## Status

Live — all four agents are running.
