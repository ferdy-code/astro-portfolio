## The problem

Every engineering team has a secret shell script someone wrote three years ago. It works — until the person who wrote it leaves, or the pipeline silently breaks on a Friday.

## The approach

DevFlow brings engineering workflows out of personal dotfiles and into versioned, observable pipelines that run identically on every machine.

- Declarative workflow files reviewed like any other code
- First-class Docker isolation, so steps can't drift between environments
- Live log streaming with structured output for every run

## The stack

Go core compiled to a single binary, gRPC between the CLI and the runner, and a React control plane for inspecting runs, logs, and historical timing.

## The outcome

Onboarding a new engineer went from a full day of setup to a single command, and the "works on my machine" class of failures simply stopped happening.
