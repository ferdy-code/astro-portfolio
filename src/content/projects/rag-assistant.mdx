## The problem

Indonesian-language documents are hard mode for retrieval: complex tables, scanned or OCR'd text, and a lack of tooling built for the language. Generic RAG stacks tend to fall over on exactly this kind of document.

## The approach

A document-based chat assistant with semantic search and citations, built to handle Indonesian-language content specifically — tables and OCR text included. The stack is provider-agnostic by design, swapping between Gemini, OpenAI, and Anthropic rather than locking into one model vendor. It builds on an earlier Indonesian legal-document RAG system already deployed on Streamlit Cloud.

## The stack

TypeScript throughout, PostgreSQL with pgvector for retrieval and Gemini as a current model provider.

## Status

Stack finalized and the skeleton is built. The evaluation layer is in progress.
